## ✨ Key Features Built

### 1. 🛍️ Customer Storefront
- **E-Commerce Catalog**:
  - Filter by category: **Jute Bags & Totes**, **Jute Mats & Rugs**, **Planters & Home Decor**.
  - Live instant search with real-time text matching.
  - Sorting: Featured, Price (Low to High), Price (High to Low), Customer Rating.
- **Product Cards & Quick View Modal**:
  - High-resolution studio photography of authentic jute products.
  - Eco-badges (*Bestseller*, *Trending*, *100% Organic*, *Artisan Choice*).
  - Material specifications, dimensions, load capacity, and care instructions.
  - Quantity counter with instant "Add to Bag" and "Buy Now".
- **Slide-Out Cart Drawer**:
  - Real-time cart calculations.
  - **Dynamic Free Shipping Progress Bar** (unlocks free shipping above ₹999).
  - Promo code discounts (e.g. `ECO10` for 10% OFF, `FREESHIP`, `KOLKATA100`).

### 2. 💳 Real Interactive Checkout & Payment Gateway
- **Customer Shipping Address Form** (Name, Phone, Email, Address, City, State, PIN Code).
- **4 Payment Methods**:
  1. **UPI / QR Code Scan**: Interactive dynamic QR code with merchant UPI ID (`dindayalropes@okhdfcbank`), deep links to GPay, PhonePe, Paytm, and BHIM, with UTR reference validation.
  2. **Credit / Debit / ATM Card**: Live card mockup that updates in real-time as the customer types card number, holder name, expiry date, and CVV.
  3. **Net Banking**: Instant selection of top Indian banks (HDFC, SBI, ICICI, Axis, PNB).
  4. **Cash on Delivery (COD)**: Contactless delivery confirmation.
- **Order Confirmation & Printable Receipt**:
  - Generates unique Order ID (e.g., `#ORD-94103`).
  - Itemized breakdown, customer address, payment status.
  - Direct **Print / Download Invoice** functionality.

### 3. ⚙️ Private Admin Portal (Hidden from Public Storefront)
Per your requirement, all visible buttons, links, and mentions of the Admin Portal have been **completely removed from the public website** (`index.html`) so customers enjoy a 100% clean shopping experience.

You can access your private Admin Portal through **two dedicated sources**:
1. **Direct Private URL**: Navigate to **[`http://localhost:3000/admin`](http://localhost:3000/admin)** (or `http://localhost:3000/admin.html`).
2. **Hidden Owner Shortcut**: Press **`Ctrl + Shift + A`** (or `Ctrl + Alt + A`) on your keyboard while browsing the customer storefront to instantly jump to the Admin Portal.

- **Passcode**: `admin123` (customizable anytime from the Settings tab).
- **Dashboard Overview**:
  - Real-time KPIs: **Total Revenue**, **Total Orders**, **Active Products**, **Low Stock Alerts**.
  - Recent orders quick table.
- **Product Management (Full CRUD)**:
  - **Add New Product**: Name, category, price, MRP, stock count, image selector (preset or URL), description, and material specs.
  - **Edit Product**: Update prices, descriptions, and details anytime.
  - **Toggle Stock Status**: Mark items as *In Stock* or *Out of Stock* with 1 click.
  - **Delete Product**: Safe removal with confirmation.
- **Orders Management**:
  - View all placed orders with customer details, items ordered, and payment methods.
  - Update status: `Placed` ➔ `Processing` ➔ `Shipped` ➔ `Delivered` ➔ `Cancelled`.
- **Edit Basic Store Details**:
  - **Change any basic detail**: Store Name, Brand Subtitle, Tagline, Phone Numbers, WhatsApp Number, Email, Office Address, GSTIN, UPI ID, Announcement Banner Text, and Free Delivery Threshold.
  - Changes save immediately and **instantly reflect across the live customer website!**

## 🚀 How to Run Locally

The site is currently running on **`http://localhost:3000`**.

To start the server manually anytime:
```powershell
node server.js
```
or
```powershell
npm start
```
Then open your browser to **`http://localhost:3000`**.
